# Pre-publication content checklist

## Required team information

- [ ] Current team name and school are visible.
- [ ] Current team email works and is team-owned.
- [ ] Current leadership and technical leads are listed.
- [ ] Current advisor information is added if approved for publication.
- [ ] Sponsor logos and links are approved and current.

## Vehicle documentation

- [ ] Current competition configuration is clearly distinguished from earlier revisions.
- [ ] Current weight is verified.
- [ ] Current lift and cruise motors and propellers are verified.
- [ ] Battery configuration is verified.
- [ ] Aircraft dimensions are added only after verification.
- [ ] Autonomy claims describe demonstrated capability accurately.
- [ ] The one-mile proof-flight video link is added.
- [ ] Major test entries include dates, objectives, configurations, results, and evidence.
- [ ] Final mission-system tests are added as they are completed.
- [ ] The Technical Design Report link is added when public.

## Website quality

- [ ] Every navigation link works.
- [ ] Search returns useful sections.
- [ ] The site works on a phone.
- [ ] Images are compressed and load quickly.
- [ ] Every meaningful image has accurate alt text.
- [ ] Videos have captions or transcripts.
- [ ] Text remains readable at 200% browser zoom.
- [ ] Keyboard focus is visible.
- [ ] No text relies on color alone.
- [ ] There are no placeholder cards or editing notices on the submitted site.

## Security and privacy

- [ ] No radio binding phrases, passwords, API keys, private IP addresses, or credentials are published.
- [ ] No private phone numbers or personal emails are published without permission.
- [ ] GPS metadata is removed from photos where appropriate.
- [ ] Sensitive flight-site coordinates and operational details are reviewed before publication.
- [ ] Team members consent to published names and photographs.
- [ ] Music and other media are licensed for public use.

## Final submission check

- [ ] Open the site in a private browser window while logged out of Rose-Hulman and GitHub.
- [ ] Test Chrome, Firefox, and Safari or Edge.
- [ ] Test a narrow mobile viewport.
- [ ] Confirm PDFs and videos are publicly accessible.
- [ ] Record the final website URL and repository commit hash.
- [ ] Preserve a ZIP backup of the submitted version.
